개인정보 처리 방침

시행일: 2026년 10월 25일 · suno-down.com

SunoDown(이하 "본 서비스")은 Suno AI 플레이리스트를 MP3·WAV 파일로 다운로드할 수 있는 무료 웹 도구입니다. 본 방침은 본 서비스가 어떤 정보를 처리하는지, 그 정보를 어떻게 보호하는지를 설명합니다.

1. 수집하는 정보

  • Suno Pro 쿠키 (선택): WAV 다운로드를 사용할 때 사용자가 직접 입력한 __client 쿠키 값. 서버 메모리에만 임시 저장되며 데이터베이스나 파일에 기록되지 않습니다.
  • 세션 식별자: 서버가 발급한 일회성 세션 ID. 서버 재시작·세션 만료·명시적 로그아웃 시 폐기됩니다.
  • 플레이리스트 URL: 사용자가 직접 입력한 Suno 플레이리스트 URL. 요청 처리 중에만 사용되며 저장되지 않습니다.
  • 접속 로그: 호스팅 인프라(Fly.io) 기본 로그 — IP 주소, User-Agent, 요청 경로·시각. 보안·디버깅 목적으로 단기 보관됩니다.
  • 브라우저 로컬 스토리지: 언어 설정, 사용자 동의 시 Suno 쿠키 자동 재접속용 키. 사용자 브라우저에만 저장됩니다.
  • 광고 관련 정보 (Google 수집): Google AdSense가 광고 게재를 위해 쿠키·기기 식별자·IP 주소·방문 페이지 URL 등을 수집할 수 있습니다. 이 정보는 Google이 직접 처리하며, 운영자는 개별 사용자를 식별할 수 있는 정보를 Google로부터 제공받지 않습니다. 자세한 내용은 6항을 참고하세요.
  • 이용 통계 (Google Analytics): 방문 페이지, 유입 경로(검색어·참조 사이트), 기기·브라우저 종류, 대략적인 지역(국가·도시), 방문 횟수와 체류 시간. 쿠키로 브라우저를 구분하지만 이름·이메일 등 개인을 식별하는 정보는 수집하지 않습니다.

2. 정보 사용 목적

  • Suno 플레이리스트 메타데이터·오디오 파일 다운로드 요청을 사용자 명의로 suno.com에 프록시
  • WAV 변환 요청 및 변환 완료 폴링 (Suno Pro 사용자)
  • 오디오·이미지 스트리밍 다운로드 (CDN 호스트 화이트리스트 검증 포함)
  • 다국어 UI 설정 유지
  • 운영비 충당을 위한 광고 게재 (Google AdSense)
  • 어떤 페이지가 도움이 되는지 파악해 서비스와 콘텐츠를 개선하기 위한 이용 통계 분석 (Google Analytics)

3. 정보 보관 및 삭제

  • Suno 쿠키: 서버 메모리에만 보관. 세션 종료·서버 재시작·"연결 해제" 클릭 시 즉시 삭제. 데이터베이스 미저장.
  • 접속 로그: Fly.io 호스팅 인프라 정책에 따라 단기 보관 후 자동 삭제.
  • 로컬 스토리지: 사용자 브라우저에 저장되며, 사용자가 브라우저 설정에서 언제든 삭제할 수 있습니다.
  • 광고 쿠키: Google 등 광고 사업자의 정책에 따라 보관되며, 사용자가 브라우저 설정에서 언제든 삭제하거나 차단할 수 있습니다.
  • 이용 통계: Google Analytics에 최대 14개월 보관된 뒤 자동 삭제됩니다. 분석 쿠키(_ga)는 최대 2년간 브라우저에 남으며 언제든 삭제할 수 있습니다.

4. 제3자 제공·이용

  • Suno AI (suno.com): 사용자가 입력한 쿠키를 사용하여 사용자 명의로 suno.com에 메타데이터·오디오 요청을 프록시합니다. 이는 사용자가 직접 suno.com과 통신하는 것과 동등합니다. 본 서비스는 사용자의 Suno 활동을 저장하지 않습니다.
  • Cloudflare: 도메인 등록·일부 트래픽 라우팅을 담당합니다.
  • Google AdSense: 본 서비스는 운영비 충당을 위해 Google AdSense 광고를 게재합니다. Google은 광고 게재와 성과 측정을 위해 쿠키·기기 식별자·페이지 URL 등을 처리합니다. 광고 쿠키와 맞춤 광고 해제 방법은 6항에서 설명합니다.
  • Google Analytics: 방문 통계를 집계하기 위해 사용합니다. Google은 분석 쿠키로 방문 정보를 처리하며, 운영자는 개인을 식별할 수 없는 집계 통계만 확인합니다.

운영자는 사용자 정보를 광고주·데이터 브로커·기타 제3자에게 판매하거나 제공하지 않습니다. 다만 4항과 6항에 설명한 대로 Google 등 광고 사업자는 자체 쿠키를 통해 정보를 직접 수집할 수 있습니다.

5. 쿠키 및 로컬 스토리지

  • __client (Suno 쿠키): 사용자가 명시적으로 입력해 WAV 다운로드에 사용. 서버 메모리에만 보관.
  • suno_clerk_cookie, suno_session_id (로컬 스토리지): 다음 방문 시 자동 재접속을 위해 사용자 브라우저에만 저장.
  • sunodown-lang (로컬 스토리지): 선택한 UI 언어를 기억하기 위해 사용.
  • Google 광고 쿠키 (제3자 쿠키): Google과 파트너가 광고 게재·노출 빈도 제한·성과 측정·맞춤 광고를 위해 설정합니다. 6항을 참고하세요.
  • _ga, _ga_* (Google Analytics 분석 쿠키): 재방문 여부와 방문 횟수를 구분하기 위해 사용. EEA·영국·스위스 사용자는 동의한 경우에만 설정됩니다.

6. 광고(Google AdSense)와 광고 쿠키

본 서비스는 운영비 충당을 위해 Google AdSense 광고를 게재하고 있습니다. 광고 게재와 관련하여 다음 사항을 알려 드립니다.

  • Google을 포함한 제3자 광고 사업자는 쿠키를 사용하여 사용자가 본 웹사이트 또는 다른 웹사이트를 이전에 방문한 기록을 바탕으로 광고를 게재합니다.
  • Google은 광고 쿠키를 사용하여, 사용자가 본 사이트 및/또는 인터넷상의 다른 사이트를 방문한 기록을 바탕으로 Google과 파트너가 사용자에게 광고를 게재할 수 있도록 합니다.
  • 사용자는 Google 내 광고 센터 또는 Google 광고 설정에서 맞춤 광고를 해제할 수 있습니다.
  • 일부 제3자 광고 사업자의 맞춤 광고용 쿠키 사용은 www.aboutads.info/choices에서 거부할 수 있습니다(EU 사용자는 www.youronlinechoices.eu).
  • Google이 이러한 정보를 사용하는 방식은 Google 서비스를 사용하는 사이트 또는 앱에서 Google이 정보를 사용하는 방법과 Google의 광고 쿠키 사용 방식에서 확인할 수 있습니다.
  • 유럽경제지역(EEA)·영국·스위스 사용자의 경우, 관련 법령이 요구하는 때에는 Google 인증 동의 관리 플랫폼(CMP)을 통해 광고 쿠키 및 Google Analytics 분석 쿠키 사용에 대한 동의를 요청하며, 동의 전에는 분석 쿠키를 설정하지 않습니다.
  • 맞춤 광고를 해제해도 광고는 계속 표시될 수 있으며, 이때는 보고 있는 페이지의 내용 등 일반적인 정보를 바탕으로 한 광고가 표시됩니다.

Privacy Policy

Effective: October 25, 2026 · suno-down.com

SunoDown ("the Service") is a free web tool that lets you download Suno AI playlists as MP3 or WAV files. This policy explains what information the Service handles and how it is protected.

1. Information We Handle

  • Suno Pro cookie (optional): The __client cookie value you paste in to enable WAV downloads. Stored only in server memory; never written to a database or file.
  • Session identifier: A one-time session ID issued by the server. Discarded on server restart, session expiry, or explicit disconnect.
  • Playlist URL: The Suno playlist URL you paste. Used only for the request in progress and not persisted.
  • Access logs: Default hosting-infrastructure (Fly.io) logs — IP address, User-Agent, request path and timestamp. Retained briefly for security and debugging.
  • Browser localStorage: Language preference and, if you opt in, keys used to re-establish your Suno cookie on next visit. Stored only in your browser.
  • Advertising data (collected by Google): Google AdSense may collect cookies, device identifiers, IP address, and the URL of the page you visit in order to serve ads. Google processes this information directly; the operator does not receive information from Google that identifies individual users. See Section 6 for details.
  • Usage statistics (Google Analytics): Pages visited, how you arrived (search terms, referring sites), device and browser type, approximate location (country/city), number of visits, and time on site. A cookie distinguishes browsers, but no name, email, or other directly identifying information is collected.

2. How We Use Information

  • To proxy playlist metadata and audio download requests to suno.com on your behalf
  • To trigger WAV conversion and poll for completion (Suno Pro users)
  • To stream audio and image files through a host whitelist that blocks SSRF
  • To remember your selected UI language
  • To display ads that help cover running costs (Google AdSense)
  • To analyze usage statistics so we can see which pages help and improve the Service and its content (Google Analytics)

3. Retention & Deletion

  • Suno cookie: In server memory only. Deleted immediately on session end, server restart, or when you click "Disconnect". Never persisted.
  • Access logs: Retained briefly per Fly.io hosting policy, then auto-deleted.
  • localStorage: Stays in your browser until you clear it via browser settings.
  • Advertising cookies: Retained according to the policies of Google and other ad vendors. You can delete or block them at any time in your browser settings.
  • Usage statistics: Kept in Google Analytics for up to 14 months, then deleted automatically. The analytics cookie (_ga) stays in your browser for up to 2 years and can be deleted at any time.

4. Third-Party Services

  • Suno AI (suno.com): When you provide your Suno cookie, we proxy metadata and audio requests to suno.com on your behalf. This is functionally equivalent to you communicating with suno.com directly. We do not track your Suno activity.
  • Cloudflare: Used for domain registration and some traffic routing.
  • Google AdSense: The Service displays Google AdSense ads to help cover its running costs. Google processes cookies, device identifiers, and page URLs to serve and measure ads. Section 6 explains advertising cookies and how to opt out of personalized ads.
  • Google Analytics: Used to compile visit statistics. Google processes visit information through analytics cookies; the operator sees only aggregated statistics that do not identify individuals.

The operator does not sell or share your information with advertisers, data brokers, or other third parties. However, as described in Sections 4 and 6, ad vendors such as Google may collect information directly through their own cookies.

5. Cookies & Local Storage

  • __client (Suno cookie): Provided explicitly by you for WAV downloads. Stored only in server memory.
  • suno_clerk_cookie, suno_session_id (localStorage): Stored in your browser only, used to auto-reconnect on your next visit.
  • sunodown-lang (localStorage): Remembers your UI language.
  • Google advertising cookies (third-party cookies): Set by Google and its partners for ad delivery, frequency capping, measurement, and personalized advertising. See Section 6.
  • _ga, _ga_* (Google Analytics cookies): Used to tell new visits from returning ones and count visits. For users in the EEA, the UK, and Switzerland, they are set only after you consent.

プライバシーポリシー

施行日: 2026年10月25日 · suno-down.com

SunoDown（以下「本サービス」）は、Suno AIプレイリストをMP3・WAVで無料ダウンロードできるWebツールです。本ポリシーは、本サービスがどのような情報を扱い、どのように保護しているかを説明します。

1. 取り扱う情報

  • Suno Pro クッキー（任意）: WAVダウンロードのために利用者が貼り付けた __client クッキーの値。サーバーメモリにのみ一時保存され、データベースやファイルには記録されません。
  • セッション識別子: サーバーが発行する一時的なセッションID。サーバー再起動・セッション期限切れ・明示的なログアウト時に破棄されます。
  • プレイリストURL: 利用者が入力したSunoプレイリストURL。処理中のみ使用され、保存されません。
  • アクセスログ: ホスティング基盤（Fly.io）の標準ログ — IPアドレス、User-Agent、リクエストパス・時刻。セキュリティ・デバッグ目的で短期間のみ保持されます。
  • ブラウザのlocalStorage: 言語設定および、同意した場合の自動再接続用キー。利用者のブラウザにのみ保存されます。
  • 広告関連情報（Googleが収集）: Google AdSenseが広告配信のため、クッキー・端末識別子・IPアドレス・閲覧ページのURLなどを収集する場合があります。これらの情報はGoogleが直接処理し、運営者が個々の利用者を特定できる情報をGoogleから受け取ることはありません。詳細は第6項をご覧ください。
  • 利用統計（Google Analytics）: 閲覧ページ、流入経路（検索語・参照元サイト）、端末・ブラウザの種類、おおよその地域（国・都市）、訪問回数と滞在時間。クッキーでブラウザを区別しますが、氏名・メールアドレスなど個人を特定する情報は収集しません。

2. 利用目的

  • 利用者の代わりにsuno.comへプレイリストメタデータ・音源リクエストをプロキシ
  • WAV変換リクエスト・完了ポーリング（Suno Pro利用者向け）
  • ホスト許可リストによるSSRF防止付きの音源・画像ストリーミング
  • 選択した表示言語の保持
  • 運営費をまかなうための広告掲載（Google AdSense）
  • 役立っているページを把握し、サービスとコンテンツを改善するための利用統計の分析（Google Analytics）

3. 保持・削除

  • Sunoクッキー: サーバーメモリにのみ保管。セッション終了・サーバー再起動・「接続解除」クリック時に即削除。データベースには保存されません。
  • アクセスログ: Fly.ioのホスティングポリシーに従い短期間保持され、自動削除されます。
  • localStorage: 利用者のブラウザに保存され、ブラウザ設定からいつでも削除できます。
  • 広告クッキー: Googleなど広告事業者のポリシーに従って保持されます。利用者はブラウザ設定からいつでも削除・ブロックできます。
  • 利用統計: Google Analyticsで最大14か月保持された後、自動削除されます。分析クッキー（_ga）は最大2年間ブラウザに残り、いつでも削除できます。

4. 第三者サービス
